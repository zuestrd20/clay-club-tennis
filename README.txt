CLAY CLUB · 紅土決勝
原創 HTML5 網球遊戲，支援電腦與手機觸控。

開啟方式
解壓縮後，用 Chrome、Edge、Firefox 或 Safari 開啟 index.html。
不需安裝、不需登入，也不需連線。也可直接開啟附帶的 Clay-Club.html 單檔版。

玩法
• 搶七：先得 7 分，並領先對手至少 2 分獲勝。
• 預設自動跑位。你控制擊球時機、蓄力與左右落點。
• 按住空白鍵或右下擊球鈕蓄力，放開擊球；第一次用來發球。
• 來球過網後開始準備，靠近時放開。可以提早約半秒準備揮拍。
• J／L 或 ↖／↗ 選擇左／右落點；再按同一方向回到中路。
• 在擊球鈕上按住後左右拖曳，也能改變擊球方向。
• WASD／方向鍵或左下搖桿手動移動，可覆蓋自動跑位。
• Esc／右上暫停鈕：暫停、查看說明或重新開始。
• ♪：開啟／關閉音效（預設關閉）。
• 開始前可切換自動跑位及休閒／標準／挑戰難度。

規則
發球必須落在斜對角發球區。一次失誤可重發，雙發失誤失分。
球沒越網、第一落點出界或落地兩次皆判分。
發球由玩家先發一分，之後每兩分交換發球方。
每分自動換左右發球區；不模擬實際網球每六分換邊。
為單人快打體驗，遊戲採搶七一局制，不模擬盤數與完整賽制。

隱私與技術
沒有帳號、分析追蹤、廣告、付費內容、後端或網路連線。
所有圖像均為原創 Canvas 場景及角色，未使用參考遊戲的商標、圖片或素材。
引擎以公尺及秒計算拋物線、重力、反彈、球網和落點。
原始碼：engine.js（球賽規則／物理），game.js（畫面／互動），index.html（介面）。
開發者測試：安裝 Node.js 後執行 node --test test.js。
